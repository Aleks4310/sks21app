## 🛠️ РАЗРАБОТКА НОВЫХ ФУНКЦИЙ

### Когда добавляете новый эндпоинт на бэкенде:

- [ ] Создан новый файл в `src/routes/`
- [ ] Создан контроллер в `src/controllers/` (если нужен)
- [ ] Маршрут зарегистрирован в `src/app.js`
- [ ] Добавлен эндпоинт в `lib/config/api_config.dart` (в ENDPOINTS)
- [ ] Написаны примеры использования в комментариях
- [ ] Протестирован через curl/Postman перед использованием на фронте
- [ ] Добавлена авторизация (если нужна)
- [ ] Написаны тесты (если используется Jest)

### Когда добавляете новый экран на фронте:

- [ ] Создан файл в `lib/screens/`
- [ ] Экран использует `ApiService` для запросов
- [ ] Добавлена обработка ошибок (try-catch)
- [ ] Показана загрузка (CircularProgressIndicator)
- [ ] Протестировано на эмуляторе/браузере
- [ ] Проверена работа в автономном режиме (graceful degradation)
- [ ] Добавлены логи для отладки

### Когда добавляете новую модель:

- [ ] Создан класс в `lib/models/`
- [ ] Реализованы методы `fromJson()` и `toJson()`
- [ ] Добавлены все поля из API ответа
- [ ] Написаны комментарии к сложным полям

## 🐛 ОТЛАДКА

### Если фронтенд не подключается к бэкенду:

- [ ] Проверен `npm start` в терминале 1 (должен быть запущен)
- [ ] Проверено, что API URL в `api_config.dart` правильный
- [ ] Проверен IP адрес (для реального устройства)
- [ ] Выполнены `flutter clean` и `flutter pub get`
- [ ] Перезагружено приложение

### Если API возвращает 401 Unauthorized:

- [ ] Проверено, что токен сохранён в `ApiService`
- [ ] Проверено, что токен передаётся в заголовок `Authorization`
- [ ] Попробована переавторизация

### Если API возвращает 404 Not Found:

- [ ] Проверено имя эндпоинта (правильное ли?)
- [ ] Проверено, что эндпоинт зарегистрирован в `src/app.js`
- [ ] Проверено, что нет опечаток в URL
- [ ] Перезагружен бэкенд (`npm start`)

### Если API слишком медленный:

- [ ] Проверены логи БД (есть ли ошибки?)
- [ ] Проверено количество запросов (нет ли лишних?)
- [ ] Добавлена пагинация для больших списков
- [ ] Кешированы часто используемые данные
