## ⚙️ Основные ошибки при разработке (которые были исправлены)

### Ошибка 1: "отношение users не существует"
**Причина:** Попытка использовать ALTER TABLE на несуществующую таблицу
**Решение:** Создать все таблицы с CREATE TABLE IF NOT EXISTS в правильном порядке

### Ошибка 2: "ошибка синтаксиса в UNIQUE constraint"
**Причина:** Использование функции DATE() в UNIQUE constraint, что не поддерживается в PostgreSQL
**Решение:** Использовать отдельный индекс вместо inline constraint
